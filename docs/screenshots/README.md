# Application Screenshots Directory

Place your application screenshots in this directory with the following recommended filenames:

1. `client_portal.png` — Contractor portal with machinery grid and active dispatches.
2. `fleet_catalog.png` — Fleet Manager equipment inventory and rate setting modal.
3. `tax_invoice.png` — Formal GST Tax Invoice modal with itemized overtime & print button.
4. `account_center.png` — Account & Executive records modal with lifetime expenditure metrics.
5. `maintenance_kanban.png` — Predictive maintenance Kanban board with telemetry thresholds.
6. `login_register.png` — Logistics-themed login & multi-tenant registration page.

These image paths are already pre-configured in the root `README.md`.
